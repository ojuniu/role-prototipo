# Rolê · app web (protótipo funcional)

Abra pelo GitHub Pages no celular e use "Adicionar à tela inicial" pra abrir como app.

**Parte 1:** mapa real, GPS, busca de destino, rota com voz, rolê com território (hexágonos), resumo, histórico e postagem.

Sem GPS ou parado? Use o botão "Simular trajeto".

Mapa: OpenFreeMap / OpenStreetMap (MapLibre). Rotas: OSRM. Busca: Nominatim. Postos: Overpass. Fotos do carro: Maxi-Napo-99 (Wikimedia Commons), CC BY 4.0.
